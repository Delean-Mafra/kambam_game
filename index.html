📖 Guia do Jogo: Regras do Kanban Squad EV (TypeScript Edition)

🎯 Objetivo do Jogo

Gerencie uma squad de tecnologia completa. Entregue valor aos clientes cumprindo prazos e SLAs, minimizando custos operacionais e evitando penalidades por atraso para maximizar o Lucro Líquido do projeto.

👥 Os 9 Especialistas do Squad & Separação Estrita de Funções

O squad conta com 9 especialistas divididos em 3 categorias. Cada função só pode atuar dentro de sua respectiva etapa:

  • 🔍 3 Analistas de Negócios (Sofia, Carlos, Mariana): Atuam EXCLUSIVAMENTE na fase de Análise & Discovery. Não podem ser alocados em Desenvolvimento ou Testes.
  • 💻 3 Desenvolvedores (Lucas, Rafael, Thiago): Atuam EXCLUSIVAMENTE na fase de Desenvolvimento. Não podem ser alocados em Análise ou Testes.
  • 🧪 3 Testadores / QA (Beatriz, Gabriela, Rodrigo): Atuam EXCLUSIVAMENTE na fase de Testes & QA. Não podem ser alocados em Análise ou Desenvolvimento.

⚡ Swarming (Concentração de Força)

Em cada cartão de sua respectiva etapa, você pode concentrar 1, 2 ou todos os 3 especialistas daquela disciplina no mesmo cartão. O modo ⚡ Swarming combina todos os dados rolados para avançar tarefas urgentes e evitar multas por atraso.

🔒 Proteção Criptográfica Anti-Tamper (Anti-Hack)

Ao exportar o arquivo de save (JSON), o jogo assina os dados com uma chave HMAC SHA-256. Caso alguém tente alterar manualmente dinheiro, dias ou dados de tarefas no arquivo, a assinatura é invalidada e o jogo bloqueia a importação.

🚀 Deploy no GitHub Pages

O projeto está 100% em TypeScript com build Vite. Para publicar no GitHub Pages, basta rodar npm run build e publicar a pasta dist/ gerada.
